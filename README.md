# WorkFlow Pro - QA Automation Case Study

This repository contains the QA Automation framework design, test scripts, and test plans for the WorkFlow Pro platform.

## Setup Instructions
1. Clone this repository.
2. Install the required Python packages: `pip install pytest playwright`
3. Install Playwright browsers: `playwright install`
4. Run tests: `pytest tests/`

## Repository Structure
* `/docs` - Test plans and testing approach documentation.
* `/tests` - Automated test scripts.
* `/data` - Mock test data.
* `/reports` - Sample test execution reports.
